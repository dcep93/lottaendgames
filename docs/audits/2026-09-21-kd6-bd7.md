# Allow Kd6 to support Bd7 with Nd3

Policy commit: `fb31c90`.

The ordinary five-diagonal placement allowance with Nd3 now includes Kd6 with either Ba4 or Bd7. The other allowed combinations remain Kc5/Kc6/Kc7 with Ba4/Bc6/Bd7. All reflections and existing boundary, race, and bishop-safety checks still apply, evaluated after White moves.

The loaded line Ba4 Ka5 now continues Bd7 rather than Bb3. A regression verifies Bd7 is supported and uniquely preferred with different counters across all eight transforms. Exhaustive king-placement tests include the new combination while retaining rejected bishop placements with Kd6. All 181 relevant tests and the build pass.

The exhaustive seven-stage audit starts from every supported seven-diagonal placement and follows all best-move ties under the application Black reply policy, retaining return history, through support changes and loss of support to mate, capture, stalemate, or cycles. Support is not terminal success. Placement counts include reflections; cyclic families are graph components, not every simple cycle.
